# Button

Primary action control.

## Rules
- Use one primary button per decision area.
- Labels start with a verb: Create store, Save changes, Connect Telegram.
- Loading state preserves width and prevents duplicate submission.
- Destructive actions require danger styling and contextual confirmation.

## AI validation
- Uses official tokens.
- Includes keyboard and screen-reader behavior.
- Includes loading, empty, error, and disabled states where applicable.
