# Error Messages

Pattern: problem → impact → recovery.

- `We could not connect this bot token. Check that it is complete and belongs to a bot you control.`
- `Payment was confirmed, but the file could not be delivered. The order remains paid. Retry delivery or contact support with the order ID.`
- `This product is out of stock. No payment has been requested.`
- `Your session expired before checkout. Review the order and try again.`
