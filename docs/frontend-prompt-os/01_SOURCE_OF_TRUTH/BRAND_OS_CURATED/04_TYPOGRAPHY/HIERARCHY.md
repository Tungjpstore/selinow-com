# Typography Hierarchy

- Marketing hero: `display-lg` or `display-xl`, maximum 12 words.
- Application page title: `h3` or `h2`.
- Card title: `h4` or 18px semibold.
- Body: 16/26.
- Dense data: 14/22.
- Labels: 14/20 semibold.
- Captions: 12/18, never for essential actions.

Use sentence case. Avoid all-caps headings; reserve uppercase for compact metadata with increased tracking.
