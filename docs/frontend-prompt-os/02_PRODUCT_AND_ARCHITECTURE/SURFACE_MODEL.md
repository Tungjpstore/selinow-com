# Surface model

## Marketing

- Light editorial canvas.
- Public SEO.
- No workspace/session assumptions.
- Runtime pricing data.

## Seller workspace

- Light content canvas + dark ink sidebar.
- Persistent shop switcher.
- Role-aware navigation.
- Action-oriented health before vanity metrics.

## Storefront

- Tenant resolved from hostname.
- Merchant brand dominates.
- Selinow semantic state colors remain protected.
- Mobile-first.

## Admin

- Dark operational console.
- Dense ledger and evidence.
- Recent-auth and explicit confirmation for risky actions.
