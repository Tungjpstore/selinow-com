# Illustration and iconography

## Illustration

Use geometric semi-flat diagrams with subtle depth:

`conversation → product → payment verification → fulfillment → delivery`

Use spacious backgrounds, controlled gradient, and real product UI fragments.

Do not use robot mascots, crypto coins, cartoon money, or glossy 3D characters.

## Icons

- 20px default; 16px compact; 24px feature.
- 1.75–2px stroke.
- Rounded joins.
- Use one icon family throughout implementation.
- State icon plus text; color alone is insufficient.
