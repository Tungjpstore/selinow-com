# Layout and density

## Marketing

- Max content width 1200px.
- 12-column desktop grid.
- Hero minimum 680px visual height on desktop.
- Section vertical spacing 96–128px desktop, 64–80px mobile.

## Workspace

- Sidebar 248px.
- Top context bar 64px.
- Main page padding 32px desktop, 20px mobile.
- Main content density is medium: row height 52–64px.
- Avoid more than four equal KPI cards in a row.

## Storefront

- Mobile-first 390px.
- Product grid 2 columns mobile only when cards remain readable; otherwise 1 column.
- Sticky cart/checkout action is allowed with safe-area padding.

## Admin

- Dense rows 44–52px.
- Use tables/ledgers, not promotional cards.
