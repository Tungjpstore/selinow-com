# Typography

- Primary: Inter Variable or existing project Inter integration.
- Monospace: JetBrains Mono only for IDs, timestamps, key metadata, code, and audit evidence.
- Do not distribute font files in this kit. Resolve fonts through the project’s approved dependency or system fallback.
- Headline uses sentence case.
- Marketing display may use gradient on a short phrase only; body text never gradient.
- Use tabular numerals for money, counts, percentages, and timestamps.
- Vietnamese diacritics must remain clear at all sizes.
