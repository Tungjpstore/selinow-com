# Operational components

## ActionQueue

Use for seller overview. It replaces decorative KPI-first design.

Row anatomy:

`severity icon | title + impact | age | count | remediation link`

## HealthRail

Use for Website, Telegram, PayOS, inventory, domain, subscription.

Each item shows:

- short human state;
- evidence/last check;
- next action;
- details route.

## ActivityLedger

Chronological, compact, auditable. Use JetBrains Mono for time/entity IDs only.
