# Error and status copy patterns

## Waiting provider

**PayOS đang kiểm tra kết nối**

Lần kiểm tra gần nhất: 2 phút trước. Selinow sẽ tự kiểm tra lại hoặc bạn có thể thử ngay.

Actions: `Kiểm tra lại` · `Xem hướng dẫn`

## Blocked

**Chưa thể publish cửa hàng**

Cửa hàng còn 2 mục bắt buộc: phương thức thanh toán và policy hỗ trợ.

Action: `Hoàn tất thiết lập`

## Safe error

**Không thể hoàn tất yêu cầu**

Hãy thử lại. Nếu lỗi tiếp tục, gửi mã `SLN-REQ-…` cho bộ phận hỗ trợ.
