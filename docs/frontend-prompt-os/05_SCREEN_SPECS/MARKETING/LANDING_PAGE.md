# Marketing landing page

## Purpose

Giải thích Selinow là commerce core cho website và Telegram, dẫn người dùng đến bắt đầu hoặc xem quy trình.

## Layout

Light-first, 1200px container, 12-column grid. Hero split 5/7 columns. Product transaction composition lớn bên phải. Chỉ một inverse section chọn lọc gần trust hoặc final CTA.

## Exact hierarchy

1. Header: logo, Sản phẩm, Giải pháp, Bảng giá, Tài nguyên, Đối tác, Đăng nhập, Bắt đầu xây cửa hàng.
2. Hero eyebrow: `NỀN TẢNG THƯƠNG MẠI CHO SẢN PHẨM SỐ`.
3. H1: `Bán sản phẩm số ngay trong cuộc trò chuyện.`
4. Supporting copy từ copy deck.
5. CTA: `Bắt đầu xây cửa hàng` + `Xem quy trình`.
6. Trust microcopy: dùng thử, không cần thẻ nếu đúng plan contract, hủy bất cứ lúc nào nếu đúng contract.
7. Hero visual: Website + Telegram → order → PayOS verified → fulfillment.
8. Proof strip: định tính hoặc dữ liệu có nguồn.
9. Commerce core workflow.
10. Ba feature stories: Bán hàng, Vận hành, Tự động hóa.
11. Product stage lớn với dashboard thật.
12. Use cases.
13. Payment/trust ownership.
14. Pricing preview runtime.
15. FAQ.
16. Final CTA và footer.


## Mandatory states

Loading pricing, pricing unavailable, navigation mobile open/closed, no fake proof data.

## Mobile 390px

Header thành logo + đăng nhập + menu 44px. Hero một cột; visual xuống dưới. Không giảm copy dưới 16px. CTA full width hoặc stacked. Sections 64–80px vertical spacing.

## Acceptance criteria

- Main value understood in first viewport.
- Exactly two hero CTAs.
- No fake metrics/testimonials.
- Pricing is runtime-driven.
- SEO metadata/canonical correct.
- No horizontal overflow at 320px.
- LCP visual has reserved dimensions.
