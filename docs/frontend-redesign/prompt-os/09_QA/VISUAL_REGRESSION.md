# Visual regression

Use Playwright or the repository’s current browser test tool.

Baseline categories:

- marketing landing/pricing/login;
- workspace overview/readiness/domain/products/inventory/orders/order detail/integrations/store builder;
- storefront home/product/cart/checkout/order states;
- admin operations;
- loading/empty/blocked/error/permission states.

Store deterministic fixtures under test-only paths. Never include real credentials, keys, contacts, or order access tokens.
