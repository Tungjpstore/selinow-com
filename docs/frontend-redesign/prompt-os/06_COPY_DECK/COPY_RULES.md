# Copy rules

- Locale chính: tiếng Việt; cấu trúc sẵn sàng cho English.
- Dùng nhất quán: cửa hàng, kênh bán, kho mã, đơn hàng, thanh toán, giao hàng, kiểm tra sẵn sàng.
- Không dùng raw machine error làm message chính.
- Không gọi Selinow là đơn vị giữ tiền hoặc bảo chứng payout.
- Không hứa tự động hoàn toàn cho BotFather, PayOS consent hoặc DNS.
- Không dùng: guaranteed sales, zero effort, risk-free, unlimited khi có limit.
- Dùng `doanh số gộp` khi metric không phải net revenue.
