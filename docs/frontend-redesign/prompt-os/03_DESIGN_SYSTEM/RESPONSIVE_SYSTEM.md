# Responsive system

| Mode | Width | Key behavior |
|---|---:|---|
| Minimum | 320px | no horizontal overflow |
| Primary mobile | 390px | full buyer critical path |
| Tablet | 768px | 8-column grid, drawer sidebar |
| Desktop | 1440px | 12-column marketing, full workspace shell |

## Workspace mobile

- Top bar: shop switcher, notifications, menu.
- Bottom nav: Tổng quan, Đơn hàng, Sản phẩm, Kênh bán, Thêm.
- Tables become labeled record lists.
- Wizard becomes progress summary + step selector.

## Storefront mobile

- One-column checkout/order/domain information.
- 44×44 minimum touch target.
- Sticky main action respects safe-area.
