# Design direction — Soft Precision Commerce

## Core idea

Selinow should feel like a friendly but exact commerce operating system.

- **Soft**: generous whitespace, rounded geometry, light surfaces, approachable copy, small success sparks.
- **Precision**: strict grid, semantic colors, restrained shadows, clear status, explicit transaction timelines.
- **Commerce**: products, orders, payment, inventory, fulfillment, and channel health are visible and understandable.

## Style blend

- 35% operational SaaS
- 25% conversational commerce
- 20% editorial minimalism
- 15% soft geometric design
- 5% playful micro-interaction

## Avoid

- generic AI neon;
- dark homepage as the dominant identity;
- robot mascot;
- excessive glass blur;
- green CTA as brand;
- card wall;
- meaningless dashboard metrics;
- visual effects that compete with payment/order clarity.

## Surface expression

- Marketing: 85% light, 10% soft tinted, 5% inverse.
- Workspace: light canvas + dark sidebar.
- Storefront: tenant brand + protected semantic states.
- Admin: dark dense operational surface.
