# Accessibility contract

- WCAG 2.2 AA.
- Normal text contrast ≥ 4.5:1.
- Large text and meaningful UI boundary ≥ 3:1.
- Visible `:focus-visible`.
- Logical tab order.
- Skip link and semantic landmarks.
- Labels and `aria-describedby` for form help/error.
- Async status uses deliberate live regions.
- Dialog traps focus, returns focus, Escape closes when safe.
- Status is never color-only.
- Reduced motion honored.
- Merchant theme cannot override protected semantic states.
