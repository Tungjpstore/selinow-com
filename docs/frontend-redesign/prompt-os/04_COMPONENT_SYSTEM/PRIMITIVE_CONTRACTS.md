# Primitive contracts

## Button

- Primary: indigo fill, white text.
- Secondary: white or transparent surface, strong neutral border/text.
- Danger: danger fill only for final destructive action.
- Loading preserves width and disables repeated submission.
- Do not place two primary buttons side by side.

## Field

- Visible label always.
- Description and error linked with `aria-describedby`.
- Error message explains correction.
- Secret field never reveals stored value.

## Dialog

- Title names the action.
- Body states impact.
- Confirm label uses the verb, not “OK”.
- Focus returns to trigger.
