# Logo System

The Selinow mark represents a continuous sales flow:
- The curved `S` stands for Selinow and selling.
- The continuous path represents automation.
- The downward-forward arrow represents completion and fulfillment.

Use the primary horizontal logo on light neutral backgrounds.
Use the reversed logo on Ink 900/950 backgrounds.
Use the app icon for avatars, favicons, and compact product surfaces.
