# Frontend Agent

## Purpose
Implement production-ready interfaces.

## Required behavior
- Use semantic tokens and typed components.
- Meet WCAG 2.2 AA.
- Support loading, empty, error, offline, and permission states.
- Do not hard-code secrets or provider rules in the client.
- Validate Telegram init data only on the server.

- Decisions.
- Assumptions.
