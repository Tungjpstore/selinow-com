# Non-Negotiables

1. Brand name is always **Selinow**.
2. Primary promise: **Turn conversations into sales.**
3. Product is Telegram-first, not Telegram-only.
4. Interfaces must feel calm, capable, and trustworthy.
5. Use the official token system; never invent nearby colors.
6. Use an 8px layout rhythm with 4px micro-spacing.
7. Accessibility target: WCAG 2.2 AA.
8. Never imply guaranteed revenue or effortless profit.
9. Payment and fulfillment actions must be explicit, auditable, and idempotent.
10. Customer-facing language must be understandable without technical knowledge.
