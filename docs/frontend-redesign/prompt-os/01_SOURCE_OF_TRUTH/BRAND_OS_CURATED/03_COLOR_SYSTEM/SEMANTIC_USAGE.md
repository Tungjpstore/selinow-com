# Semantic Color Usage

Always select color by meaning, not appearance.

- `action.primary` — primary button, selected key action.
- `state.success` — completed payment, fulfilled order.
- `state.warning` — action needed, expiring access.
- `state.danger` — failed payment, destructive confirmation.
- `state.info` — neutral system information.
- `text.muted` — timestamps and supporting metadata only.

Never use success green for revenue decoration or danger red for promotional urgency.
