# Progressive enhancement

Before scripts execute:

- headings and landmarks exist;
- form labels exist;
- catalog/product content exists;
- links work where a link is sufficient;
- server-rendered state is readable.

Scripts enhance:

- drawer/dialog;
- clipboard;
- optimistic form feedback;
- cart convenience;
- autosave;
- device preview;
- polling/retry status.

Script failure must not expose data or create duplicate mutations.
