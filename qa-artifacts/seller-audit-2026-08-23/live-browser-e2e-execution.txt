EVIDENCE BOUNDARY

This ledger contains only actions and results recorded from the real Chrome
session. It does not treat source review, Vitest, Playwright staging/local runs,
curl/HTTP probes, API contract inspection, or static route discovery as live
browser evidence. A route is listed as BLOCKED when the retained Chrome record
is not sufficient to assert a result. No logout, payment, subscription, domain,
credential, destructive, fulfillment, or production-data cleanup action was
performed.

Result labels:
- PASS: the recorded browser result matched the limited expectation stated.
- FAIL: Chrome directly displayed an incorrect result or an operation failed.
- BLOCKED: the action was deliberately not performed, could not safely proceed,
  or the retained live evidence is insufficient to claim PASS/FAIL.
